# 🎓 Sistema de Gestão de Alunos

Sistema de terminal (CLI) desenvolvido em Python para gerenciar o cadastro de alunos e suas respectivas notas. O projeto foca em lógica de programação, manipulação de estruturas de dados (Listas e Dicionários) e persistência de informações em arquivos locais.

## 🚀 Funcionalidades

O sistema oferece um menu interativo com as seguintes operações:

- ✅ **Cadastrar:** Adiciona novos alunos com validação de entrada para notas.
- 📋 **Listar:** Exibe todos os alunos e suas notas.
- 🔍 **Consultar:** Busca um aluno específico pelo nome.
- ❌ **Remover:** Exclui um aluno da base de dados.
- 📊 **Média:** Calcula e exibe a média de notas de toda a turma.
- 💾 **Persistência:** Salva os dados em `alunos.txt` ao sair e os carrega ao iniciar.

## 🛠️ Tecnologias Utilizadas

- **Linguagem:** Python 3
- **Módulos Nativos:** `os`, `time`
- **Conceitos:** CRUD, Dicionários, Tratamento de Exceções (`try/except`), Manipulação de Arquivos.
